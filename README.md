# Юля - Бумм! — интерактивный прототип

Короткий статический прототип будущего сайта студии организации праздников «Юля - Бумм!».

- три переключаемых арт-направления;
- адаптивный маршрут от выбора события до демонстрационной заявки;
- понятное окно со статусом готовых и будущих функций;
- без серверной части и без отправки персональных данных.

Откройте `index.html` локально или используйте GitHub Pages. Исходная страница также сохранена под рабочим именем `julia-site-preview.html`.
